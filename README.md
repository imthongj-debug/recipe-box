# Recipe Box

เว็บแอป **Recipe Box** สำหรับจัดเก็บและจัดการสูตรอาหาร โดยผู้ใช้สามารถค้นหา ดู เพิ่ม แก้ไข และลบสูตรอาหารได้ผ่านหน้าเว็บ พร้อมเชื่อมต่อกับ REST API ฝั่งเซิร์ฟเวอร์

## ความสามารถของแอป

- แสดงรายการสูตรอาหาร
- ค้นหาสูตรอาหาร
- กรองสูตรอาหารตามหมวดหมู่
- ดูรายละเอียดสูตรอาหาร
- เพิ่มสูตรอาหารใหม่
- แก้ไขสูตรอาหาร
- ลบสูตรอาหาร
- เชื่อมต่อ Frontend กับ Backend ผ่าน REST API
- รองรับการใช้งานบนหน้าจอขนาดต่าง ๆ (Responsive UI)
- ส่วนติดต่อผู้ใช้เป็นภาษาไทย

## เทคโนโลยีที่ใช้

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- REST API
- JSON สำหรับจัดเก็บข้อมูล

## โครงสร้างโปรเจกต์โดยย่อ

```text
recipe-box/
├── client/
│   ├── index.html
│   ├── style.css
│   └── script.js
├── server/
│   ├── server.js
│   ├── package.json
│   └── data/
│       └── recipes.json
└── README.md
```

> ชื่อไฟล์หรือโครงสร้างย่อยอาจแตกต่างเล็กน้อยตามเวอร์ชันของโปรเจกต์

## วิธีติดตั้ง

เปิด Terminal หรือ Command Prompt แล้วเข้าไปยังโฟลเดอร์โปรเจกต์ จากนั้นติดตั้ง dependencies ด้วยคำสั่ง

```bash
npm install
```

## วิธีรันโปรเจกต์

รันโปรเจกต์ด้วยคำสั่ง

```bash
npm run dev
```

เมื่อเซิร์ฟเวอร์เริ่มทำงานแล้ว ให้เปิด URL ที่แสดงใน Terminal เช่น

```text
http://localhost:3000
```

> หากโปรเจกต์เวอร์ชันที่ใช้งานไม่ได้กำหนด script `dev` ไว้ใน `package.json` ให้ตรวจสอบ scripts ในไฟล์ดังกล่าวก่อนรัน

## REST API Endpoints

| Method | Endpoint | รายละเอียด |
|---|---|---|
| `GET` | `/api/recipes` | ดึงรายการสูตรอาหารทั้งหมด และรองรับการค้นหา/กรองข้อมูล |
| `GET` | `/api/recipes/:id` | ดึงรายละเอียดสูตรอาหารตาม ID |
| `POST` | `/api/recipes` | เพิ่มสูตรอาหารใหม่ |
| `PUT` | `/api/recipes/:id` | แก้ไขสูตรอาหารตาม ID |
| `DELETE` | `/api/recipes/:id` | ลบสูตรอาหารตาม ID |

### ตัวอย่างการค้นหา/กรองข้อมูล

สามารถส่ง query parameters ไปกับ endpoint รายการสูตรอาหาร เช่น

```text
GET /api/recipes?search=ผัด
GET /api/recipes?category=อาหารไทย
```

## การทดสอบระบบ

สามารถทดสอบการทำงานของ API และหน้าเว็บได้ เช่น

1. เปิดหน้า Recipe Box
2. ตรวจสอบว่ารายการสูตรอาหารถูกโหลดจาก API
3. ทดลองค้นหาสูตรอาหาร
4. ทดลองกรองตามหมวดหมู่
5. ทดลองเพิ่มสูตรอาหาร
6. ทดลองแก้ไขสูตรอาหาร
7. ทดลองลบสูตรอาหาร
8. ตรวจสอบผลลัพธ์จาก REST API
