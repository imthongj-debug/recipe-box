สามารถเพิ่มสูตรอาหารของตัวเองได้ไหม?

ได้เลย กดปุ่มเพิ่มสูตรอาหาร แล้วกรอกหมวดหมู่ วัตถุดิบ ขั้นตอน และเวลาทำอาหาร

สามารถแก้ไขสูตรอาหารภายหลังได้ไหม?

ได้ ทุกสูตรรองรับการจัดการแบบ CRUD ได้แก่ ดู เพิ่ม แก้ไข และลบ

สามารถค้นหาจากวัตถุดิบได้ไหม?

ได้ ช่องค้นหาจะค้นจากชื่อสูตร หมวดหมู่ และข้อความในรายการวัตถุดิบ

Recipe Box ใช้ API ภายนอกหรือไม่?

ไม่ใช้ โปรเจกต์นี้สร้างและใช้งาน Express REST API ของตัวเองตามข้อกำหนดของ Mini โปรเจกต์
